# Language Policy

> **Languages**: [English](#english) | [日本語](#原文)

---

# English

To foster an inclusive environment where developers from around the world can participate comfortably, **michiu** adopts a flexible multilingual communication policy.

Our core principle is:

> **Interactive communication can be multilingual, while static and structural elements remain English-only.**

- **English = Project Interface** (Searchability, consistency, tooling)
- **Your Preferred Language = Human Communication** (Detailed thoughts and nuances)
- **Original Language = Semantic Authority** (The primary source of truth if ambiguity arises)

Community members are always welcome to help refine or polish translations!

## Policy Summary

| Item                             | Policy                                                                                        |
| :------------------------------- | :-------------------------------------------------------------------------------------------- |
| **Title**                        | **English only**                                                                              |
| **Summary / TL;DR**              | **English only**                                                                              |
| **Official Labels / Categories** | **English only** (Managed by maintainers)                                                     |
| **Body & Detailed Descriptions** | **Your preferred language is encouraged** (*Please accompany it with an English translation). |
| **English Translation**          | **AI / Machine translations** (ChatGPT, DeepL, etc.) are more than welcome.                   |
| **Ambiguity in Translation**     | **The original text takes precedence** as the primary source of truth.                        |
| **Display Order**                | Place **English on top**, followed by the original language below.                            |
| **Docs & Code Comments**         | **English only**                                                                              |
| **Commit Messages**              | **English only**                                                                              |

---

## Writing Example (Issues / Discussions / PRs)

When opening an issue, discussion, or PR, please place an English translation (machine translation is totally fine!) at the top, and your original language below:

> **[English]** _(AI / Machine translation)_  
> When clicking the button, nothing happens. I expected the counter to increment by 1.
>
> **[日本語 / Original]**  
> ボタンをクリックしても何も反応しません。カウンターが1増えることを期待していました。

# 原文

世界中の開発者が参加しやすい環境を作るため、**michiu** では柔軟な多言語運用ポリシーを採用しています。

基本方針は以下の通りです：

> **ディスカッションなどの対話（コミュニケーション）は多言語歓迎、ドキュメントやシステム側の構造的記述は英語のみ**

- **英語 = project interface**（検索性・一貫性・ツール連携のため）
- **好きな言語 = human communication**（細かなニュアンスや正確な思考を伝えるため）
- **原文 = semantic authority**（翻訳の解釈が分かれた場合の第一情報源）

コミュニティメンバーによる翻訳のブラッシュアップや修正提案も大歓迎です！

## ポリシー概要一覧

| 項目                             | 方針                                                    |
| :------------------------------- | :------------------------------------------------------ |
| **タイトル**                     | **英語のみ**                                            |
| **要約**                         | **英語のみ**                                            |
| **公式ラベル・カテゴリ**         | **英語のみ**（運営が管理）                              |
| **本文・重要な説明**             | **母語・得意な言語を推奨**（※英訳の併記をお願いします） |
| **英訳**                         | **AI / 機械翻訳**（ChatGPT, DeepL 等）でOK              |
| **翻訳の解釈が分かれる場合**     | **原文（母語）を最優先**して扱います                    |
| **表示順**                       | **英語を上、原文・他言語を下**に配置してください        |
| **ドキュメント・コードコメント** | **英語のみ**                                            |
| **コミットメッセージ**           | **英語のみ**                                            |
