# English

## Supported Versions

Please refer to the table below for the versions of this project that currently receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a vulnerability, please report it using the following method:

- **GitHub Private Vulnerability Reporting**: Go to the **Security** tab of this repository → **[Advisories](https://github.com/eto0202/michiu/security/advisories)** to report it.

### What to include in your report

- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue or a proof-of-concept (PoC).
- The affected version(s).
- Any potential mitigations you have identified (if any).

### What to expect

- We will acknowledge receipt of your report typically within a few days to a week.
- We will keep you updated on the progress of resolving the issue.
- Once fixed, we will publish a security advisory and credit you (unless you prefer to remain anonymous).

## サポート対象バージョン

現在セキュリティアップデートが提供されているバージョンは以下の通りです。

| ---------- | ------------------ |

## 脆弱性の報告方法

**公開のIssue（GitHub Issues）には脆弱性の情報を書き込まないでください。**

脆弱性を発見した場合は、以下の方法でご報告をお願いします。

- **GitHubの非公開報告機能**: 本リポジトリの「Security」タブ →「[Advisories](https://github.com/eto0202/michiu/security/advisories)」から報告してください。

### 報告に含めていただきたい内容

- 脆弱性の概要と想定される影響
- 再現手順またはPoC（概念実証コード）
- 影響を受けるバージョン
- 提案可能な対策（あれば）

### 報告後の対応について

- ご報告から数日〜1週間程度を目安に受領確認のご連絡をいたします。
- 修正対応の進捗について定期的に共有いたします。
- 修正が完了した後にセキュリティアドバイザリを公開し、ご希望に応じてクレジット（お名前）を掲載いたします。
